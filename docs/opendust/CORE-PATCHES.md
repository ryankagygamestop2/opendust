# Core patches

Every change to a file outside `modules/opendust_*`, `docs/opendust/`, `tools/`, `demo/`, and the
root branding files (`OPENDUST.md`, `CLAUDE.md`, `version.py`, `.gitignore`, `.mcp.json`) is a core
patch and must be listed here with the reason and the upstream status.

| file | reason | upstream status |
|---|---|---|
| `version.py` | branding: `short_name`, `name`, `website`, `docs`; adds `opendust_version` | never upstreamed (fork identity) |

(no functional core patches yet)
